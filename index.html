How I check AI's work (2 min)

The game, and who did what

The honest split

  • I chose the book, the ending, the scope and the art direction. I set the bar each phase had to pass, and I checked the work: screenshots, dialogue, playthroughs.
  • Claude wrote the code, the tools and the text drafts, and ran the checks I asked for.
  • The point: with skill, taste and care, AI help can make something human and delightful. You do not have to take my word for it. The game is one click away, and so is everything that went wrong first.

What failed first: in February 2026 an image model drew the sprite sheets, and frames drifted, directions swapped and backgrounds stayed opaque. In October I switched to open Liberated Pixel Cup art composed by code, and every sheet is checked by a script.

How I check AI's work

The game's own checks

  • Nine headless tests run on every change: quests, farming, crafting, the ending.
  • A sheet checker reads every sprite sheet: sizes, transparency, each frame inside its cell, feet on the same line.
  • A browser script plays the whole game from the title screen to the credits. Before each step it waits for the game's own console line, such as [Dialogue] start hermes_intro or [GameState] Planted moly, so nothing is assumed.
  • One command imports, tests, exports the web build and takes the screenshots on this page.

What I do with the results

  • I read the screenshots and the dialogue myself and send back what is wrong, in plain words.
  • A fix is done when the script plays through again with zero problems, not when the code looks right.
  • Numbers I show are the smaller ones I can defend. The game's scorecard lists the gaps too.
